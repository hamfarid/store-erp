   Settings → Secrets and variables → Actions
   
   Add minimum secrets:
   - PROD_DATABASE_URL
   - PROD_SECRET_KEY
   - PROD_JWT_SECRET
   
   Generate: python -c "import secrets; print(secrets.token_hex(32))"

   git checkout -b test/ci-setup

   Watch workflow run in GitHub Actions
