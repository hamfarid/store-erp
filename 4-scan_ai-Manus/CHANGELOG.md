- نظام تشخيص أمراض النباتات بالذكاء الاصطناعي
- نظام إدارة المزارع والمحاصيل
- نظام المصادقة والتفويض (JWT)
- واجهة برمجة التطبيقات RESTful

- نظام النسخ الاحتياطي

- إعداد Docker Compose للتطوير والإنتاج
- سير عمل CI/CD مع GitHub Actions
