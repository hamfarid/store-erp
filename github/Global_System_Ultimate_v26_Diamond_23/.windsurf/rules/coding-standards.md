# Coding Standards for Windsurf IDE

## 1. General Principles
- **Clarity over Cleverness:** Write code that is easy to read and understand.
- **Consistency:** Follow the project's style guide.
- **Modularity:** Break down complex logic into smaller, reusable functions.

## 2. Python
- Follow PEP 8.
- Use type hints.
- Document all functions and classes.

## 3. JavaScript/TypeScript
- Use ESLint and Prettier.
- Prefer `const` over `let` and `var`.
- Use async/await for asynchronous operations.

## 4. Testing
- Write unit tests for all new features.
- Aim for high code coverage.
