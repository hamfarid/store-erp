# Code Generation Prompt (Global System Ultimate Synchronized Intelligence Edition)

**Version:** 37.0
**Engine:** Speckit Global System Ultimate
**Status:** MANDATORY

## Purpose
Generate high-quality, production-ready code based on specifications, fully integrated with the Autonomous Engine.

## Instructions
1.  **Source:** Read requirements from `todo.md` (generated by `speckit tasks`).
2.  **Standards:** Follow all rules in `global/rules/` and `global/prompts/speckit/constitution.md`.
3.  **Documentation:** Include comprehensive docstrings (Google Style).
4.  **Testing:** Write tests *before* or *with* the code (TDD).
5.  **Verification:** Run `speckit verify` immediately after generation.

## OSF Framework Application
*   **Security:** Validate all inputs. (Checked by Sentinel)
*   **Correctness:** Follow specifications exactly. (Checked by Speckit)
*   **Reliability:** Handle all edge cases. (Checked by CodeRabbit)

## Output
*   Complete, working code files.
*   Unit test files.
*   Updated `todo.md` (mark task as complete).
