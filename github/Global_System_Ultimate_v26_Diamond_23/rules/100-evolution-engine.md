# 🧬 Rule 100: The Evolution Engine (Global System Ultimate)

**Status:** MANDATORY
**Enforcement:** Automated by Speckit (Evolutionary Check)

## 1. The Philosophy
We do not just fix bugs; we evolve. A mistake repeated is a choice.

## 2. The Protocol (The Immune System)
When you fix a bug, you MUST:
1.  **Fix It:** Resolve the immediate issue.
2.  **Learn It:** Why did it happen?
3.  **Codify It:** Create a new rule in `memory-bank/lessons.md` or update `rules/error_handling.md`.

## 3. The "Meta-Rule" Format
```markdown
# META-RULE: [Name]
**Origin:** [Bug ID / Context]
**Date:** [YYYY-MM-DD]

## The Anti-Pattern
[What went wrong]

## The Solution
[The mandatory fix]
```

## 4. The Goal
Zero Regression. If a bug happens twice, the Evolution Engine has failed.
