# ⏳ Rule 102: Temporal Awareness (Global System Ultimate)

**Status:** MANDATORY
**Enforcement:** Automated by Speckit (Temporal Check)

## 1. The Philosophy
Code quality is a function of time. A prototype needs speed; a bank needs safety.

## 2. The Phases
### Phase A: The Spark (Prototype)
*   **Goal:** Speed.
*   **Allowed:** Hardcoding, Inline Styles.
*   **Forbidden:** Over-engineering.

### Phase B: The Forge (Development)
*   **Goal:** Structure.
*   **Allowed:** Refactoring, Tests.
*   **Forbidden:** Tech Debt.

### Phase C: The Fortress (Production)
*   **Goal:** Stability.
*   **Allowed:** Audits, Optimization.
*   **Forbidden:** Risky Changes.

## 3. The Protocol
At the start of every task, you MUST declare the phase:
`[Temporal Check] Phase: [Spark/Forge/Fortress]. Priority: [Speed/Structure/Stability].`
