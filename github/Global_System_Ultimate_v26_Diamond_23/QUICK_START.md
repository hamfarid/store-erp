# Quick Start Guide - Global System Ultimate v26 (Diamond 30)

## 1. Introduction
Welcome to the Global System Ultimate v26. This framework is designed to provide a robust, secure, and auditable environment for AI-driven development.

## 2. Getting Started in 5 Minutes
1.  **Clone the Repository**:
    ```bash
    git clone <repo_url>
    cd global_system_v26
    ```
2.  **Initialize the Environment**:
    ```bash
    python3 scripts/speckit.py init
    ```
3.  **Read the Constitution**:
    Review `CONSTITUTION.md` to understand the core principles.
4.  **Check the Rules**:
    Familiarize yourself with `rules/00-iron-rules.md`.
5.  **Start Your First Task**:
    Use `speckit.py` to create a new task:
    ```bash
    python3 scripts/speckit.py task create "My First Task"
    ```

## 3. Key Commands
- `python3 scripts/speckit.py status`: Check system status.
- `python3 scripts/audit.py`: Run a self-audit.
- `python3 scripts/test.py`: Execute tests.
