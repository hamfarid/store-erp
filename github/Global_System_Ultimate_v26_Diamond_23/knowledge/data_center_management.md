# Data Center & Big Data Management (v2026.2)

## 1. Infrastructure
- **Compute:** Spark Clusters (Databricks/EMR).
- **Storage:** HDFS / S3 / Azure Blob.
- **Orchestration:** Airflow / Prefect.

## 2. Data Governance
- **Catalog:** Apache Atlas / Amundsen.
- **Access Control:** Ranger / IAM.
- **Lineage:** OpenLineage.

## 3. Operations
- **Monitoring:** Prometheus + Grafana (Cluster Health).
- **Scaling:** Auto-scaling groups based on CPU/Memory.
- **Cost:** Spot instances for batch jobs.

## 4. Integration with ML
- **Feature Engineering:** Spark SQL -> Parquet -> Feature Store.
- **Training:** Distributed Training (Horovod / PyTorch DDP).
