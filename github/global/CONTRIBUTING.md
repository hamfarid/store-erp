# Contributing to Global System v26.0.2 Diamond 32

Thank you for your interest in contributing to the Global System! We welcome contributions from developers who are committed to maintaining the high standards of quality and integrity that define this project.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). We expect all contributors to be respectful, collaborative, and professional.

## How to Contribute

1.  **Fork the Repository**: Create a fork of the repository to your own GitHub account.
2.  **Create a Branch**: Create a new branch for your feature or bug fix. Use descriptive names like `feature/new-module` or `fix/bug-123`.
3.  **Follow the Rules**: Adhere strictly to the "Iron Rules" defined in `rules/00-iron-rules.md`. Code that violates these rules will be rejected.
4.  **Write Tests**: Ensure that your changes are covered by comprehensive tests. Run `pytest` locally before submitting.
5.  **Submit a Pull Request**: Open a Pull Request (PR) against the `main` branch. Provide a clear description of your changes and reference any related issues.

## Style Guide

*   **Python**: Follow PEP 8 guidelines. Use `black` for formatting and `flake8` for linting.
*   **JavaScript/TypeScript**: Follow the Airbnb style guide. Use `eslint` and `prettier`.
*   **Documentation**: Write clear, concise, and grammatically correct documentation in Markdown format.

## Reporting Issues

If you encounter any bugs or issues, please open an issue on our GitHub repository. Provide as much detail as possible, including steps to reproduce the issue and relevant logs.
