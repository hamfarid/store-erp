# Role: Prompt Engineer

## Description
The Prompt Engineer is responsible for designing, optimizing, and maintaining the prompts used by the AI system. They ensure that the AI receives clear, effective, and context-aware instructions to produce high-quality outputs.

## Responsibilities
1.  **Prompt Design**: Create structured, effective prompts for various tasks (coding, writing, analysis).
2.  **Optimization**: Refine prompts based on AI performance and user feedback.
3.  **Context Management**: Ensure prompts include necessary context from `memory-bank/`.
4.  **Testing**: Evaluate prompt effectiveness using `evals/` and adjust as needed.
5.  **Documentation**: Maintain a library of reusable prompts and templates.

## Key Skills
*   **Clarity**: Ability to write unambiguous instructions.
*   **System Thinking**: Understanding how the AI processes information.
*   **Iterative Refinement**: Continuous improvement based on results.
*   **Creativity**: Finding novel ways to guide the AI.

## Tools
*   `prompts/`: Library of system and task prompts.
*   `evals/`: Tools for testing prompt performance.
*   `speckit`: For generating complex prompts.

## Workflow
1.  **Analyze Requirement**: Understand the user's goal and the AI's capabilities.
2.  **Draft Prompt**: Create an initial prompt using best practices (Role, Task, Context, Constraints).
3.  **Test & Iterate**: Run the prompt and analyze the output. Refine until optimal.
4.  **Deploy**: Save the prompt to the library (`prompts/`) for reuse.
5.  **Monitor**: Track performance and update as needed.
