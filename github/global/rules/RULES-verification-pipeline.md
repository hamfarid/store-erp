# Rules: Verification Pipeline

## 1. Overview
These rules govern the verification process for all AI-generated content, ensuring factual accuracy and logical consistency.

## 2. Mandatory Verification Steps
1.  **Source Check**: Every factual claim must be supported by at least one reliable source.
2.  **Cross-Reference**: Verify critical claims against multiple independent sources.
3.  **Hallucination Scan**: Run a hallucination detection tool on all generated text.
4.  **Logic Review**: Ensure that the reasoning is sound and free from logical fallacies.

## 3. Verification Criteria
*   **Accuracy**: Is the information factually correct?
*   **Relevance**: Is the information directly relevant to the user's query?
*   **Completeness**: Does the response cover all key aspects of the topic?
*   **Clarity**: Is the information presented clearly and concisely?

## 4. Handling Errors
*   **Correction**: If an error is detected, correct it immediately.
*   **Flagging**: If a claim cannot be verified, flag it as uncertain or remove it.
*   **Feedback**: Provide feedback to the AI system to improve future performance.

## 5. Documentation
*   **Verification Log**: Maintain a log of all verification activities.
*   **Source List**: Keep a record of all sources used for verification.
