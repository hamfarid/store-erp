# Workflow: Memory Lifecycle

## 1. Overview
This workflow outlines the process for managing the lifecycle of AI memory, ensuring that it remains accurate, relevant, and efficiently stored.

## 2. Steps
1.  **Extraction**: Identify and extract key information from conversations.
2.  **Update**: Add new information to the memory bank.
3.  **Consolidation**: Merge redundant or outdated memories.
4.  **Pruning**: Remove information that is no longer useful.
5.  **Verification**: Ensure that the memory bank is accurate and consistent.

## 3. Tools
*   `extract_memories`: Identify key information from text.
*   `update_memory`: Add or modify entries in the memory bank.
*   `consolidate_memories`: Merge related memory entries.
*   `prune_memories`: Remove outdated or irrelevant information.

## 4. Roles
*   **Memory Guardian**: Oversees the memory lifecycle.
*   **Context Engineer**: Ensures that the context is relevant and concise.
*   **Fact-Checker**: Verifies the accuracy of the memory bank.

## 5. Output
*   **Updated Memory Bank**: The latest version of the memory bank.
*   **Memory Log**: A record of all memory operations and changes.
