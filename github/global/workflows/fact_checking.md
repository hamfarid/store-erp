# Fact Checking Workflow

## Purpose
This workflow ensures the accuracy and reliability of all information generated by the AI system, preventing hallucinations and ensuring that outputs are based on verified facts.

## Steps
1.  **Trigger**: A factual claim or complex reasoning is generated by the AI.
2.  **Identify Claims**: Isolate specific statements that require verification.
3.  **Verify**: Check each claim against trusted sources (internal/external).
    *   **Internal**: `memory-bank/`, `knowledge/`, documentation.
    *   **External**: Search engines, official documentation, credible websites.
4.  **Flag Issues**: Mark any unverified or incorrect information.
5.  **Correct**: Provide the correct information with citations.
6.  **Report**: Document the findings and suggest improvements to the system.

## Roles Involved
*   **Fact Checker**: Responsible for executing the verification.
*   **Prompt Engineer**: Provides the prompt and context for the verification.
*   **Researcher**: Provides the external sources for verification.
