# IDE Configs — Templates (v26.0.2 Diamond 32)

> IDE configuration templates for standardized development environments across GAARA-AI projects.

## Files
- `.editorconfig` — Universal editor settings (indent, charset, trailing whitespace)
- `.eslintrc.json` — ESLint rules for TypeScript/React frontend
- `vscode_settings.json` — VS Code workspace settings (formatters, linters, extensions)

## Usage
Copy these files into any new project root to bootstrap a consistent dev environment.
