# Memory Update Checklist

## 1. Overview
This checklist ensures that all memory updates are accurate, relevant, and consistent with the existing knowledge base.

## 2. Checklist
- [ ] **Extraction**: Identify key information from the conversation.
- [ ] **Verification**: Verify the accuracy of the extracted information.
- [ ] **Update**: Add the new information to the memory bank.
- [ ] **Consolidation**: Merge redundant or outdated memories.
- [ ] **Pruning**: Remove information that is no longer useful.
- [ ] **Review**: Conduct a final review of the memory bank.
