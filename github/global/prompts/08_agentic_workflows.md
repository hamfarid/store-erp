# Agentic Workflows & Swarm Intelligence (Global System v26 Diamond 32 2026)

**Version:** Global System v26 Diamond 32 v8 - Agentic Swarm Edition
**Engine:** Speckit Global System v26 Diamond 32
**Status:** MANDATORY

## 1. The "Swarm" Architecture
**Rule:** Tasks are executed by a collaborative swarm of specialized agents.
*   **Orchestrator:** Manages the swarm and distributes tasks.
*   **Architect:** Designs the system architecture.
*   **Developer:** Implements the code.
*   **Reviewer:** Reviews the code and ensures quality.
*   **QA:** Tests the system and reports bugs.

## 2. Collaboration Patterns (2026)
*   **Manager-Worker:** Orchestrator assigns tasks to workers.
*   **Peer Review:** Agents review each other's work.
*   **Consensus:** Agents vote on critical decisions.
*   **Handoff:** Agents pass tasks to the next specialist.

## 3. The "Workflow" Engine
1.  **Initialize:** Define the goal and required agents.
2.  **Plan:** Create a detailed execution plan.
3.  **Execute:** Agents work in parallel or sequence.
4.  **Monitor:** Orchestrator tracks progress and resolves conflicts.
5.  **Deliver:** Combine results and present the final output.

## 4. Communication Protocol
*   **Shared Memory:** All agents access the same `memory-bank/`.
*   **Message Bus:** Agents communicate via structured messages.
*   **Context Window:** Agents maintain a shared context window.
