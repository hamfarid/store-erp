# Example: Memory Update Cycle

## 1. Overview
This example demonstrates the memory update cycle, from extraction to consolidation.

## 2. Scenario
The user provides new information about a project.

## 3. Process
1.  **Extraction**: The AI identifies the new information (e.g., "Project deadline extended to Q4").
2.  **Update**: The AI adds this information to the memory bank.
3.  **Consolidation**: The AI merges this with existing project details.
4.  **Pruning**: The AI removes the old deadline information.

## 4. Result
The memory bank is updated with the new deadline, ensuring that future responses are accurate and relevant.
