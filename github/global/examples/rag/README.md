# 🧠 RAG Architecture (Synchronized Intelligence Edition)

This directory contains a reference implementation for **Retrieval-Augmented Generation (RAG)** using the Global AI System Global System v26 Diamond 32 stack.

## 🏗️ Stack Components
1.  **ChromaDB**: Vector Database for storing embeddings.
2.  **Ollama**: Local LLM runner (Llama 3, Mistral, etc.) for embedding generation and inference.
3.  **FastAPI**: Backend API to orchestrate the flow.
4.  **Redis**: Caching frequent queries.

## 🚀 Quick Start

1.  **Initialize Project:**
    ```bash
    python3 global/setup_project.py my_rag_app
    cd my_rag_app
    ```

2.  **Provision Stack:**
    The system will auto-detect `rag_engine.py` or `chromadb` usage and provision the containers.
    ```bash
    python3 global/tools/container_manager.py --provision
    ```

3.  **Start Services:**
    ```bash
    docker-compose up -d
    ```

4.  **Ingest Data:**
    ```bash
    python3 global/tools/rag_engine.py --ingest ./data/my_document.txt
    ```

5.  **Query:**
    ```bash
    python3 global/tools/rag_engine.py --query "What is the main topic?"
    ```

## 📂 File Structure
- `rag_api.py`: FastAPI application exposing RAG endpoints.
- `ingest_worker.py`: Background worker for processing documents.
- `docker-compose.yml`: Auto-generated by `container_manager.py`.

## 🧠 Level 12 Features
- **Auto-Model Pulling**: The system checks for required models (`nomic-embed-text`, `llama3`) and pulls them if missing.
- **Persistent Storage**: ChromaDB data is persisted in `chroma_data` volume.
- **GPU Acceleration**: Docker Compose is pre-configured for NVIDIA GPU support if available.
