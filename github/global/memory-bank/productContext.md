# Product Context (Global System v26 Diamond 32)

## Vision
To create a **self-sustaining, autonomous AI development ecosystem** that empowers users to build complex software systems with minimal friction. The Global System v26 Diamond 32 acts as a "Meta-OS" for AI agents, providing standardized protocols, memory management, and toolchains.

## Core Value Proposition
1.  **Autonomy:** Agents can self-heal, self-correct, and self-improve.
2.  **Standardization:** A unified way to structure projects (`memory-bank`, `knowledge/`, `tools/`).
3.  **Security:** Built-in safeguards against prompt injection and data leaks (`OSF Framework`).
4.  **Agnosticism:** Works with any LLM (Claude, GPT, Gemini) and any IDE (VS Code, Cursor).

## Target Audience
*   **AI Engineers:** Building agentic workflows.
*   **Software Developers:** Using AI to accelerate coding.
*   **Enterprises:** Deploying secure, governed AI systems.

## Key Features
*   **Unified Memory Bank:** Persistent context across sessions.
*   **Context Budget Manager:** Smart token management.
*   **Pre-flight Checks:** Automated system integrity verification.
*   **Augment Protocol:** Self-improving code analysis.
*   **Kiro & Kilo:** Orchestration and Execution engines.
