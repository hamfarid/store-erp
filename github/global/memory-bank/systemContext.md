# System Context (Global System v26 Diamond 32)

## Architecture Overview
The **Global System v26 Diamond 32** is a comprehensive governance framework designed to standardize AI agent behavior across multiple platforms (Cursor, Cline, Windsurf, etc.). It acts as a "Meta-OS" for AI development.

## Core Components

### 1. Rules Engine (`rules/`)
*   **Purpose:** Enforce strict behavioral protocols.
*   **Key Files:** `00_iron_rules.md`, `AGENTS.md`, `AI_HANDBOOK.md`.

### 2. Knowledge Base (`knowledge/`)
*   **Purpose:** Provide educational workflows and best practices.
*   **Key Files:** `OSF Framework`, `Zero-Tolerance Rules`, `Architecture Guides`.

### 3. Toolchain (`tools/`)
*   **Purpose:** Automate repetitive tasks and enforce compliance.
*   **Key Scripts:**
    *   `activate_global.py`: Bootstraps new projects.
    *   `preflight_check.py`: Verifies system integrity.
    *   `augment.py`: Enhances code quality.
    *   `genesis.py`: Creates project structure.

### 4. Memory Bank (`memory-bank/`)
*   **Purpose:** Serve as the single source of truth for project context.
*   **Key Files:** `activeContext.md`, `decisionLog.md`, `lessons.md`.

## Design Philosophy
*   **Zero Hallucination:** Enforced by strict rules and pre-flight checks.
*   **Self-Documentation:** Every decision and lesson is logged.
*   **Visual Logic:** Complex workflows are visualized with Mermaid charts.
*   **Version Agnostic:** The system evolves without breaking changes.
