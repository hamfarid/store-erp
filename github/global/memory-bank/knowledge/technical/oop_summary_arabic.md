# ملخص مفاهيم البرمجة كائنية التوجه (OOP)

هذا الملف يحتوي على ملخص شامل لمفاهيم البرمجة كائنية التوجه (Object-Oriented Programming) كما تم استخلاصها من المواد التعليمية المرفقة.

## 1. المفاهيم الأساسية (Basic Concepts)

### ما هي OOP؟
هي طريقة في البرمجة (Paradigm) تجعل الكود سهل الاستخدام، قابل لإعادة الاستخدام، وأكثر تنظيماً من خلال محاكاة الأشياء الواقعية كـ "كائنات" (Objects).

### المبادئ الأربعة (The 4 Pillars):
1.  **التغليف (Encapsulation)**: إخفاء البيانات الداخلية للكائن وحمايتها.
2.  **الوراثة (Inheritance)**: قدرة كلاس جديد على اكتساب خصائص كلاس موجود مسبقاً.
3.  **تعدد الأشكال (Polymorphism)**: قدرة الكائن على اتخاذ أشكال متعددة أو التصرف بطرق مختلفة.
4.  **التجريد (Abstraction)**: إخفاء التفاصيل المعقدة وإظهار الوظائف الضرورية فقط.

---

## 2. التفاصيل والتعريفات

### التغليف (Encapsulation)
هو أسلوب يمكن اتباعه لإخفاء البيانات الأساسية في الكلاس، أي لإخفاء الخصائص الموجودة فيه وجعل الكلاسات الأخرى قادرة على التعامل مع هذه الخصائص فقط من خلال دوال يقوم بإنشائها المبرمج الأساسي للكلاس (Getters & Setters).

### الوراثة (Inheritance)
هي عملية إنشاء كلاس جديد بناءً على كلاس سابق، فتمكننا من إعادة استخدام أكواد مكتوبة سابقاً، وتعديل بعضها أو إضافة خصائص جديدة بدل من إعادة كتابتها كل مرة. وتسمى الفئة (Class) التي نرث منها بالأب (Parent) والتي تُورث إليها بالابن (Son).

### تعدد الأشكال (Polymorphism)
تعني أن الكائن يمكن أن يتخذ أكثر من شكل. والفكرة ببساطة أن مجموعة كائنات ترث خصائصها من أب واحد، لكن كل منهم يقوم بتعديل هذه الخصائص لتقوم بأمر مختلف.

### التجريد (Abstraction)
هو أسلوب يستخدم لإخفاء تفاصيل تنفيذ البرنامج ويستخدم لتسهيل كتابة الأوامر وتنفيذ ما تريد دون الحاجة إلى معرفة كافة التفاصيل إذا يجعلك تتعامل مع الأشياء بسطحية.

## 3. الفروقات والمقارنات

### الفرق بين Overloading و Overriding
*   **Overloading**: تعني تعريف أكثر من دالة أو كونستركتور لهم نفس الاسم ولكن مختلفون في عدد أو نوع البارامترات (Parameters). أي تجهيز عدة دوال لهم نفس الاسم وهذه الدوال تكون متشابهة من حيث الوظيفة ولكن مختلفة قليلاً في الأداء.
*   **Overriding**: تعني تعريف الدالة التي ورثها الـ Subclass من الـ Superclass من جديد حيث تكون مشابهة للدالة الموروثة حيث لها نفس الاسم و النوع و عدد البارامترات لكن محتواها مختلف بهدف إتاحة الفرصة للـ Subclass ليعرف الدوال حسب حاجته.

### الفرق بين Interface و Abstract Class
*   **Interface**: هي عبارة عن اتفاقية ما بين مبرمجه وما بين المبرمج اللي هيستخدم الـ Interface والاتفاقية بتقول انه لو عاوز يستخدم الـ Functions اللي في الـ Interface لازم يكتب بيديه الكود بتاع الـ Functions دي. الدوال في Interface مجردة كلياً (Full Abstract) لا تحوي أي implementation أي أنها لا تقوم بتنفيذ شيء حتى يرثها الصف الابن ويقوم بعمل override.
*   **Abstract Class**: هو الكلاس الذي يحتوي على كلمة abstract في تعريفه او يحتوي على دوال تم تعريفها كـ Abstract method فيصبح هو ايضا abstract class ولا يمكن انشاء objects منه وانما يتم توريثه لكلاس آخر، واعادة تعريف كل الـ abstract methods. في حين abstract class يمكن أن يحوي على دوال تقوم بتنفيذ سلوك افتراضي ثم يأتي الصف الابن إما أن ينفذ هذا السلوك نفسه أو سلوك آخر أيضاً بعملية override.

### الفرق بين Class و Object
*   **Class**: الفئة هي عبارة عن نموذج أو وصف للكائن (blueprint).
*   **Object**: الكائن هو عبارة عن نسخة من هذه الفئة (instance).
    *   مثال: 3 Objects في الغرفة دي؟
        *   الكرسي كائن من كلاس كرسي.
        *   الترابيزة كائن من كلاس ترابيزة.
        *   الباب كائن من كلاس باب.

### الفرق بين Static و Const
*   **Static**: يستخدم للمتغيرات او الدوال اللي استدعاؤه باسم الكلاس وبدوء انشاء كائن.
*   **Const**: يستخدم مع المتغيرات المعروف قيمتها ولن تتغير مثل سرعه الضوء.

### الفرق بين Setter و Getter
*   **Setter**: الـ Setter هي دالة تكون void ولها بارامتر وتستخدم لإستقبال المعلومات.
*   **Getter**: الـ Getter يكون لها return type وتستخدم للحصول على المعلومات.

### الفرق بين Event و Delegate
*   **Event**: هو الحاجة اللي ال User بيعملها وبناءاً عليها ببقى عاوز انفذ كود، زي لو ال User داس على زر فى ال Keyboard ده يسمى Event.
*   **Delegate**: بتربط ال Function اللي انا عاوزها تتنفذ بال Event اللي عاوزها تتنفذ فيه.

## 4. المفاهيم المتقدمة

### ما هو Constructor؟
هو عبارة عن دالة لها نوع خاص، يتم استدعائها أثناء إنشاء كائن لتوليد قيم أولية للخصائص الموجودة فيه أي أنه لا يمكن إنشاء كائن من كلاس إلا من خلال Constructor.
*   **أنواعه**:
    *   Parameterized constructors: بداخله متغير أو أكثر.
    *   Parameterless constructors: يقوم بإنشائه المترجم من تلقاء نفسه.
*   **هل ينفع يكون عندي اكثر من Constructor؟**: نعم يمكن انشاء أكثر من واحد.
*   **هل ينفع يكون Constructor نوعه Private؟**: ايوه ينفع بس وقتها مش هنقدر نعمل كائن من الكلاس دا.
*   **هل ينفع يكون Constructor نوعه synchronized & final & abstract & Static؟**: لا لا يسمح ان static, abstract, synchronized or final.

### ما هو Copy Constructor؟
يستخدم لإنشاء كائن جديد باستخدام كائن قديم ويبقي نسخة من القديم.

### ما هو Destructor؟
هو دالة في كلاس تقوم بتعطيل الذاكرة المخصصة لأحد الكائنات (تدمير الكائنات) يتم تعريفه بنفس الاسم مثل اسم الكلاس، مسبوقاً برمز (~).

### الفرق بين Constructor و Destructor

| Constructor | Destructor |
| :--- | :--- |
| توليد الكائنات فى الذاكرة. | تدمير أماكن الكائنات في الذاكرة. |
| يستخدم معاملات. | لا يستخدم معاملات. |
| يحتوي الكلاس على واحد او أكثر. | يحتوي الكلاس على واحد فقط. |

### ما هو Enumerator؟
هو مجموعة من القيم الثابتة المرتبطة ببعضها.

### ما هو pure virtual function؟
هي دالة تستخدم في الكلاس الاب فقط مثل overriding.

### ما هو ال Static method او static members؟
هي ال Methods او ال Attributes بقدر انادى عليها من اسم ال Class.
*   **كيفية استدعاء Static method؟**: بكتابة اسم الكلاس ثم (.) ثم اسم الدالة مثل (ClassName.methodName).

### ما المقصود ب Applet؟
هو برنامج مكتوب بصورة معينة بلغة ال java تجعله قابل للتضمين داخل صفحة HTML.

### يعني ايه diamond problem وايه حلها؟
مشكله ناتجة عند التوريث المتعدد فاذا كان لدينا (A class & B class & C class) حيث ان C يرث من B, A يرث من C فاذا أراد الكلاس A ان يرث من B أيضا فتنتج المشكلة وهي تكرار الأوامر حيث ان C يحتوي على أوامر B لأنه يرث منه وعندما ورث A من C فهو قد ورث أوامر B بشكل غير مباشر فعدما يطلب A الوراثة من B يحدث تكرار للأوامر.

## 5. أمثلة كود (Code Snippets)

### دالة للتحقق من العدد الأولي (Prime Number Check)
```java
public static boolean isPrime(int n) {
    if (n <= 1) {
        return false;
    }
    for (int i = 2; i < Math.sqrt(n); i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}
```
