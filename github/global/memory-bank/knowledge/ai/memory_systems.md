# أنظمة الذاكرة في الذكاء الاصطناعي (AI Memory Systems)

## 1. المقدمة
الذاكرة هي العمود الفقري لأي نظام ذكاء اصطناعي متقدم، حيث تمكنه من الاحتفاظ بالسياق، التعلم من التفاعلات السابقة، وتجنب التكرار. في هذا النظام، نعتمد نهجاً هجيناً يجمع بين الذاكرة قصيرة المدى وطويلة المدى.

## 2. أنواع الذاكرة

### أ. الذاكرة قصيرة المدى (Short-Term Memory)
*   **الوظيفة**: الاحتفاظ بسياق المحادثة الحالية (Current Context).
*   **الآلية**: تعتمد على `context window` الخاص بالنموذج (LLM).
*   **الاستخدام**: تذكر آخر الأسئلة والأجوبة، التعليمات المؤقتة، وحالة المهمة الحالية.
*   **التحدي**: محدودة بحجم الـ Token Limit وتتلاشى بمجرد إغلاق الجلسة.

### ب. الذاكرة طويلة المدى (Long-Term Memory)
*   **الوظيفة**: تخزين المعلومات الدائمة، القواعد، والدروس المستفادة عبر المشاريع.
*   **الآلية**:
    1.  **نظام الملفات (File-based)**: مثل `memory-bank/` الذي يحتوي على ملفات Markdown منظمة (`activeContext.md`, `projectBrief.md`).
    2.  **قواعد البيانات المتجهة (Vector DB)**: (مخطط له في التحديثات القادمة) لتخزين واسترجاع المعلومات دلالياً (Semantic Search).
*   **الاستخدام**: تخزين تفضيلات المستخدم، قواعد المشروع، الأخطاء التي يجب تجنبها (`lessons_learned`).

## 3. هيكل الذاكرة في هذا النظام (Memory Bank)

يعتمد النظام على مجلد `memory-bank` كذاكرة حية، ويحتوي على:

| الملف | الوظيفة |
| :--- | :--- |
| `projectBrief.md` | وثيقة تأسيس المشروع، الأهداف، والنطاق. |
| `activeContext.md` | حالة العمل الحالية، الخطوة التالية، والقرارات الأخيرة. |
| `productContext.md` | سياق المنتج، لماذا نبنيه، ولمن. |
| `systemPatterns.md` | القرارات المعمارية، الأنماط المتبعة، والمعايير التقنية. |
| `techContext.md` | التقنيات المستخدمة، التبعيات، وإعدادات البيئة. |
| `progress.md` | ما تم إنجازه، ما تبقى، وحالة المهام. |

## 4. استراتيجيات الحفاظ على السياق

1.  **التحديث المستمر**: يجب تحديث ملفات `memory-bank` بعد كل خطوة مهمة.
2.  **التلخيص (Summarization)**: عندما يطول السياق، يتم تلخيص الأحداث القديمة ونقلها للأرشيف مع الاحتفاظ بالنقاط الرئيسية.
3.  **الحقن (Injection)**: يتم حقن محتويات الملفات المهمة في بداية كل جلسة (System Prompt) لضمان أن النموذج "يتذكر" كل شيء.

## 5. أفضل الممارسات
*   لا تعتمد على ذاكرة النموذج الضمنية فقط.
*   وثّق القرارات فور اتخاذها.
*   استخدم `lessons_learned` لتجنب تكرار الأخطاء.
