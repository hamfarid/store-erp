# CrossCheck Protocol (v26.0.2 Diamond 32 GAARA AI)

**Objective:** Eliminate self-preference bias in AI code generation by enforcing multi-model verification.

## 1. The Problem: Self-Preference Bias
Research shows LLMs rate their own outputs significantly higher than objective quality metrics. This leads to "blind spots" where a model fails to catch its own logic errors.

## 2. The Solution: Cross-Model Verification
The CrossCheck pattern mandates that critical code generated by one model family (e.g., Claude) MUST be reviewed by a different model family (e.g., GPT-4o or DeepSeek).

### 2.1 Implementation
*   **Generator:** Claude 3.5 Sonnet (Primary Coding Agent)
*   **Reviewer:** GPT-4o / DeepSeek-V3 (via MCP or API)

### 2.2 Workflow
1.  **Generate:** Agent writes code.
2.  **Tag:** Commit message includes `Co-Authored-By: Claude-3.5-Sonnet`.
3.  **Detect:** CI/CD pipeline detects the generator model.
4.  **Review:** `mcp-code-crosscheck` triggers a review from the alternative model family.
5.  **Report:** Reviewer posts comments on PR/Commit.

## 3. Git Hooks
*   `/security-review`: Checks for 10 common threat categories (OWASP).
*   `/bug-review`: Checks for 10 common failure modes (Logic, Edge Cases).

## 4. Tools
*   **mcp-code-crosscheck:** Automated MCP server for cross-model review.
*   **Promptfoo:** Used for deterministic assertions.
