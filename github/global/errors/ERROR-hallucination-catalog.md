# Hallucination Catalog

## 1. Overview
This catalog lists common types of hallucinations and their potential causes.

## 2. Types
| Type | Description | Cause |
|---|---|---|
| **Factual Error** | Incorrect statement of fact. | Outdated knowledge, incorrect source. |
| **Logical Fallacy** | Flawed reasoning or argument. | Poor logic, bias. |
| **Fabrication** | Invented information or event. | Creative writing, lack of constraints. |
| **Contradiction** | Conflicting statements within the same response. | Inconsistent context, poor memory management. |

## 3. Prevention
*   **Fact-Checking**: Verify all claims against reliable sources.
*   **Logic Review**: Ensure sound reasoning.
*   **Context Management**: Provide relevant and consistent context.
